# Student Result and Grade Management System

The Student Result and Grade Management System is a web-based application for managing university academic records from course registration through publication of official results. It supports role-based workflows for students, instructors, the Registrar, and the Department Head, including grade processing, GPA/CGPA calculation, transcripts, and re-evaluation.

## Main Features

- Role-based login for Students, Instructors, the Registrar, and the Department Head
- Course registration with credit-load validation
- Grade entry, validation, and submission by instructors
- Registrar review, approval, and publication of results
- Semester GPA and CGPA calculation
- Printable grade reports and transcripts
- Re-evaluation requests and review

## Tools and Technologies

- **Language:** Java
- **Web application:** Java web framework to be confirmed by the group/instructor
- **Database:** MySQL
- **IDE:** NetBeans
- **Testing:** JUnit 4
- **Modeling:** Enterprise Architect
- **Version control:** Git and GitHub (student-name branches and pull requests)
